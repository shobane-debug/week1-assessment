# Week 1 Assessment - Main Version

A beginner-friendly solution covering Python fundamentals/OOP, CSV and JSON file I/O, a REST API request, NumPy, Pandas, Matplotlib, Jupyter and Git.


## Setup

```bash
python -m venv .venv
# Windows PowerShell: .venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env  # Windows: copy .env.example .env
```

The JSONPlaceholder endpoint is public and does not need an API key. Keep any real credentials in `.env`; never commit it.


## Run

```bash
python src/assessment.py
jupyter notebook notebooks/week1_analysis.ipynb
```


## Files
- `data/employees.csv`: assessment's 8 original employees.
- `data/departments.csv`: departments, example heads and sample budgets; Marketing intentionally has no employees.
- `data/employees_with_issues.csv`: added two missing salaries and one duplicate row for the cleaning exercise.
- `src/assessment.py`: Tasks 1–3, including API safeguards and chart generation.
- `notebooks/week1_analysis.ipynb`: notebook walkthrough with timing and analysis.
- `reports/`: four saved chart images generated by Task 3.


## Five-line findings summary
1. The original employee file contains 8 records.
2. Five employees have salaries above ₹50,000.
3. IT has the largest headcount with 3 employees.
4. Chennai has 4 employees in the provided data.
5. Marketing is the sample department with no employees; Finance has the highest average salary among populated departments.


## Charts and interpretations
- `department_headcount.png`: IT has the highest headcount (3).
- `salary_histogram.png`: salaries range from 30,000 to 90,000.
- `salary_scatter.png`: displays salary by employee ID; IDs are labels and should not be interpreted causally.
- `average_salary_line.png`: Finance has the highest department mean salary in this sample.
